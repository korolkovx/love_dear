# 💌 Love Dear — Интерактивное приглашение на свидание

Романтический интерактивный сайт с анимациями, защитным слоем для стирания («Сотри меня ✨»), убегающей кнопкой «Нет», салютом из сердечек, интерактивным выбором сценария свидания, еды, времени и формированием персонального VIP-билета с отправкой ответа в Telegram!

## ✨ Что внутри:
1. **Стирающийся защитный слой («Сотри меня ✨»)**
   - Реалистичный скретч-слой с мерцанием и искрами (работает на смартфонах и компьютерах).
   - Автоматическое открытие при стирании ~40% или по кнопке «Открыть сразу ✨».
2. **Вопрос: «Ты пойдёшь со мной на свидание?»**
   - Милая анимация с котиками.
   - **Убегающая кнопка «Нет»** с забавными фразами при попытке нажатия.
   - Кнопка **«Да!»**, которая увеличивается и сияет при каждой попытке нажать «Нет».
3. **Реакция-сюрприз («Подожди, ты правда сказала ДА?! 🥰»)**
   - Взрыв конфетти и радостные эмоции.
4. **Выбор сценария свидания**
   - Уютная кофейня, романтический ужин при свечах, киновечер с попкорном, прогулка под вечерними огнями, свидание на крыше / закат, PlayStation дома, творческий мастер-класс или свой вариант в текстовом поле.
5. **Выбор еды и угощений**
   - Пицца, суши, паста, бургеры, рамен и роллтон.
6. **Выбор даты и времени**
   - Быстрые варианты («В эту пятницу вечером», «В субботу днем/вечером») или календарь с выбором точного времени.
7. **Персональный VIP-билет на свидание**
   - Стильный билет с перфорацией и печатью «Одобрено с любовью».
   - Кнопка **«Отправить ответ в Telegram 💌»** (открывает диалог с готовым текстом сообщения).
   - Кнопка **«Скопировать ответ 📋»** для пересылки в любой мессенджер.
8. **Звуковые эффекты**
   - Синтезированы через Web Audio API (не требуют загрузки внешних mp3, работают везде).

## 🚀 Как выложить на GitHub Pages

Вы уже создали репозиторий `love_dear` на GitHub (`korolkovx/love_dear`). Чтобы сайт стал доступен по ссылке:

1. Откройте терминал в папке проекта и выполните:
```bash
cd /Users/storage/Downloads/love_dear
git remote add origin https://github.com/korolkovx/love_dear.git
git push -u origin main
```

*(Если репозиторий на GitHub был создан с README или лицензией, выполните `git push -u origin main --force`)*

2. В репозитории на GitHub перейдите в:
   **Settings** (Настройки) → **Pages** (слева)
3. В пункте **Branch** выберите ветку **`main`** и папку **`/ (root)`**, затем нажмите **Save**.
4. Через 1 минуту ваш сайт будет доступен по ссылке:
   👉 **`https://korolkovx.github.io/love_dear/`**
